ADD YOUR PROJECT VIDEOS HERE

This folder is where the video previews for your three project pages belong.
Use MP4 video files (H.264 video is a good compatibility choice) and keep these exact filenames:

  project-1.mp4  -> projects/project-1.html
  project-2.mp4  -> projects/project-2.html
  project-3.mp4  -> projects/project-3.html

The video files are not included because you have not supplied recordings yet.
Once an MP4 with the matching filename is added here and committed to GitHub,
the video player on the matching project page will load it automatically.

For a different filename or video format, update the <source src="..."> line
on the corresponding project HTML page.
