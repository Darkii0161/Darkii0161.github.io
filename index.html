Self Summary

I'm a self-taught programmer who started to learn how to code in Lua using the engine Roblox Studio in 2019; however, it was a rough beginning.

When I started to learn the basics of coding, I would use other people's code and tinker with it in all sorts of ways to turn a single result into a tree of many. There was plenty of trial and error, and the memory of the syntax behind what everything meant could never stay in my head, but eventually everything clicked.

In recent times, most of my work involves programming C++ in class and building things hands-on. I enjoy working through problems, understanding how systems fit together, and turning an idea into something playable or useful.

Outside of coursework, I've been developing projects in Roblox Studio. For the past couple of years, I've been working on game exploit software, using it to find vulnerabilities in my own projects so I can strengthen my AC within future projects that I work on. I'm always looking for something new to work on to broaden my skills.
